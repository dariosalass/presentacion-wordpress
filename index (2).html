Error al establecer la conexión con la BD

localhost/wordpress/

Error establishing a database connection

This either means that the username and password information in your wp-config.php file is incorrect or that contact with the database server at localhost could not be established.

Ni carga el idioma
Qué vimos

Al fallar la base de datos, WordPress ni siquiera carga el idioma y muestra el error en inglés.

Causa

WordPress no consigue leer las tablas de MySQL.

Solución

Abrir wp-config.php y comprobar que estos 4 datos coinciden con la base de datos creada:

DB_NAME
DB_USER
DB_PASSWORD
DB_HOST

MySQL se detuvo durante la práctica

Incidencia real No la provocamos: nos pasó de verdad.

Qué pasó

XAMPP mostró “MySQL shutdown unexpectedly” y la web dejó de conectar con la base de datos.

Causas típicas

Puerto 3306 ocupado por otro programa, falta de permisos o un cierre incorrecto.

Cómo lo resolvimos

Volvimos a arrancar el módulo MySQL y el estado pasó a “running”. Si se repite, revisar Logs y el puerto.

Roles de usuario: de más a menos permisos

AdministradorControl total: temas, plugins y usuarios
EditorPublica y borra contenido de cualquiera
AutorPublica solo sus entradas
ColaboradorEscribe, pero envía a revisión
SuscriptorLee, comenta y edita su perfil

Cada persona, el rol mínimo que necesita: un redactor en prácticas sería Colaborador, no Administrador.
En nuestra instalación: un único usuario, admin, con rol Administrador.
